# Agent workspace

This directory contains development-process state, not application behavior.

- `POLARIS.md` defines the product outcome and hard health measures.
- `specs/` defines evidence required for feedback-sensitive changes.

Implement, document, and verify directly. Do not write a plan or create planning files unless the user
explicitly requests one. Keep temporary verification evidence here only while needed; remove it after
acceptance or when the user requests cleanup.

Do not store conversations, credentials, machine-specific paths, product facts already owned by
`docs/`, or copies of external workflow instructions here.
