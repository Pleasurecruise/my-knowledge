# Retrieval evaluation

Use for AI Search query, ranking, threshold, authorization, or result-shaping changes.

1. Freeze an approved or synthetic corpus, expected invariants, baseline, and candidate settings.
2. Run both variants on the same examples and retain per-example results.
3. Measure retrieval relevance, private-result exclusion, and citation or link validity as applicable.
4. Reject any candidate that regresses privacy or authorization.
