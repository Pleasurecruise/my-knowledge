# References and reuse

[Obsidian](https://help.obsidian.md/) informs portable Markdown, hierarchical tags, explicit links, backlinks, and graph navigation. [my-memos](https://github.com/Pleasurecruise/my-memos) informs the chronological index, reading/editor interactions, owner authentication, and shared API credential. The owner-local `my-profile` repository informs reading composition. These references do not change this application's routes or storage boundaries.

Use official [MCP](https://modelcontextprotocol.io/), [OpenNext](https://opennext.js.org/cloudflare), [Cloudflare](https://developers.cloudflare.com/), and [Vite Plus](https://viteplus.dev/) documentation for platform contracts. Other visual references include docu.md and tw93/Kami. References are not automatically runtime dependencies.

Before reuse, inspect licensing, maintenance, compatibility, transitive dependencies, security, and replacement cost. Validate the closest real Worker or browser entrypoint and adopt the smallest useful surface. Do not copy code, skills, fonts, templates, or assets without license review. The requested my-memos reuse has an AGPL-3.0 review; its third-party materials still need independent compatibility checks. The unlicensed markdown-viewer skill source remains unbundled.

Browser Run or Sandbox experiments require a concrete benefit, scoped credentials, confirmed account/cost decisions, and teardown. They do not replace local verification or become application dependencies merely because they appear in a reference.
